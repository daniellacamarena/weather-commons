# 31 · Hail Daniella Camarena

Author: Daniella · Started: 2026-11-02 · Status: sketch · Stack: static HTML + JS

A first page about hail and who it reaches. It asks: when a hailstorm is coming, who gets a warning in time to protect crops, homes and bodies, and who is left to count the damage afterwards?

## Run

Online, once published: `https://daniellacamarena.github.io/weather-commons/31-hail-daniella-camarena/`

On your computer:

```bash
cd sketches/31-hail-daniella-camarena
python -m http.server 8000
```

Then open http://localhost:8000.
